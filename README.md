 Dataset Description

The dataset used in this project is the *StudentPerformanceFactors* dataset, which contains various features that may influence student academic performance. These features include both numerical and categorical variables such as study habits, attendance, and other related factors.

The dataset provides a comprehensive view of different aspects that can affect student outcomes, making it suitable for data analysis and preprocessing tasks. It includes a mix of continuous values and categorical labels, which requires proper handling before applying any machine learning techniques.

This dataset is used in this project to demonstrate key preprocessing steps such as handling missing values, removing outliers, scaling numerical features, and applying dimensionality reduction using PCA.
